Measured result, reported honestly

The original scope targeted "~20% higher accuracy than baseline." The actual measured lift is +1.89% (86.89% → 88.52%), evaluated on the same held-out test split for both models. A 10-fold cross-validation sweep across the full dataset confirms why: Logistic Regression (84.46% mean accuracy) is a genuinely strong, close-to-linear baseline for this small, well-studied dataset — Random Forest (82.82%) and Gradient Boosting (79.49%) don't reliably beat it here. That's a known property of the Cleveland dataset, not a pipeline bug — and it's a more credible story than a manufactured 20%.

Dataset

UCI Heart Disease dataset (Cleveland subset) — 303 patient records, 13 clinical attributes, fetched programmatically via ucimlrepo. This is a public benchmark research dataset, not live clinical data.

Janosi, A., Steinbrunn, W., Pfisterer, M., & Detrano, R. (1988). Heart Disease [Dataset]. UCI Machine Learning Repository. doi.org/10.24432/C52P4X

Model selection

Baseline: plain Logistic Regression, single 80/20 split, no tuning. Improved: Random Forest tuned via GridSearchCV over n_estimators, max_depth, min_samples_split, min_samples_leaf, with StratifiedKFold(5) cross-validation. Both evaluated on the identical held-out test set.
